# STM32U5 Secure & Complete Password Holder

This project is designed to be a copmplete and total alternative to managed password holders. Including features  like one click copy for authenticators  which allows the same acces as a microsoft auth. but with more controll. Additionaly features like autofill, and hardware key capabilities are all wraped in the same authenticator. THere is one universal settings and interface (HTML) to allow for any device with a browser to open and use passwords. This board was desiged as complete alternative to web extentions or websites having a data breach and you loosing all of your passwords. Features to prevent this are the Phishing noteices where when you attempt to fill in your password or use the device on a site like G00gle.com instead of google.com, a popup will appear informing you of a potential scam. As well as autogenerated secure passwords, week password indicators, and very good cryptography. This device uses a locked to pin system and ATECC608A binding points. With more updates to come. I built this project because I was tired of Google asking me to save every password and wanted a local opensource alternitive that does it all.
